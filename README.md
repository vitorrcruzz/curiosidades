# Curiosidades

Um site interativo desenvolvido com HTML, CSS e JavaScript que exibe uma curiosidade nova a cada dia, usando a [Useless Facts API](https://uselessfacts.jsph.pl/). O usuário também pode visualizar o histórico de curiosidades já vistas, alternar entre temas claro e escuro e armazenar tudo localmente no navegador.

## Funcionalidades

- Exibe automaticamente uma nova curiosidade a cada dia.
- Usa a API pública `uselessfacts.jsph.pl`.
- Armazena o histórico das curiosidades por data (via `localStorage`).
- Permite alternar entre modo claro e modo escuro.
- Mostra estatísticas de uso (quantas curiosidades já foram vistas).
- Possui botão para visualizar curiosidades passadas (histórico).
- Layout responsivo e centralizado.
- Salva preferências localmente (tema e idioma futuramente).

## Tecnologias Utilizadas

- HTML5 – Estrutura da aplicação  
- CSS3 – Estilização com suporte a temas  
- JavaScript (Vanilla JS) – Lógica da aplicação  
- API Pública: [Useless Facts API](https://uselessfacts.jsph.pl/)
